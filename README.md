# Escalonamento de Tarefas Críticas de Voo

Projeto desenvolvido em C para a disciplina de Infraestrutura de Software.

O programa simula o escalonamento de tarefas periódicas utilizando dois algoritmos:

- Rate-Monotonic (Rate)
- Earliest-Deadline-First (EDF)

A simulação considera período, deadline e tempo de execução de cada tarefa, além de situações de preempção, perda de deadline e encerramento da simulação.
